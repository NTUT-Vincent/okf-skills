# Empty OKF Template

This bundle is intentionally minimal. It contains only one reusable example concept.

## Usage

1. Copy `example.md`.
2. Rename the copied file with a stable kebab-case filename.
3. Replace every placeholder.
4. Add authoritative sources for important claims.
5. Add a real `verified` record only after review.
6. Update this index when new concepts are added.
